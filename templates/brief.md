# Brief template (CoS → Manager, and Manager → Worker)

The recipient starts from zero. The brief must be enough to do the work without asking back.

```
## Goal
<1–2 sentences: what to do, why, for whom>

## Rigor level: <LIGHT | THOROUGH>

## Context
<current state; related tickets, commits, files>

## Scope
- Do: <list>
- Do NOT do: <list — state it explicitly, even the obvious>

## Related files / sources
- <path> — <why it needs to be read>

## Prohibitions (beyond the common forbidden list)
- <example: do not touch the deploy config files>

## What done means
- [ ] <a checkable criterion, not vague; for optimization work record the measurement before and the threshold to reach>

## How to verify
<commands to run test/build, what to look at, the expected result>

## Hand back
Per templates/worker-report.md
```
